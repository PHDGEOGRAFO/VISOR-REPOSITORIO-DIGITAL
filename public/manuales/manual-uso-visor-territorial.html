Crear cartografía propia

El visor no es solo una herramienta de consulta. El usuario puede construir su propia cartografía temática activando y combinando coberturas, seleccionando el área de interés, ajustando encuadre y escala y usando las herramientas de navegación, consulta, análisis y dibujo.

  • Activar una o varias coberturas desde el Índice.
  • Dejar visibles únicamente las capas necesarias para el objetivo del mapa.
  • Usar selección de puntos, polígonos, consultas espaciales y herramientas SANTI.
  • Preparar el encuadre y escala final del plano.
  • Usar la opción PDF / Imprimir para imprimir directamente el plano o guardarlo como archivo PDF.

Esto permite generar mapas de apoyo para reuniones, revisión territorial, informes y presentaciones sin necesidad de utilizar software SIG de escritorio.

Usuarios con experiencia SIG

Para análisis más avanzados, el Índice de Coberturas permite descargar GeoPackage (GPKG) cuando se encuentre disponible y autorizado. Estos archivos pueden abrirse en QGIS o ArcGIS para realizar cruces espaciales, análisis de atributos, simbología avanzada, edición autorizada y generación de nueva cartografía.

Las versiones descargables corresponden a coberturas depuradas para publicación y deben excluir campos sensibles.

Alcance de la información

La información contenida en el visor proviene de Direcciones y oficinas municipales, levantamientos propios, catastros, encuestas y otras fuentes similares. Su finalidad es apoyar la revisión, comparación y análisis territorial de la comuna de Santiago.

Resumen de uso

1. Índice de Coberturas

Permite buscar coberturas por dimensión, sector, nombre, geometría, registros, estado y fuente. Desde el índice se pueden activar capas y acceder a descargas autorizadas.

2. Mapa territorial

Permite visualizar comuna, territorios, barrios, manzanas INE 2024, puntos, líneas y polígonos. Las capas pueden combinarse para análisis comparativo.

3. Herramientas SANTI

Permiten consultar coberturas, contar registros, seleccionar puntos, dibujar polígonos, usar buffer, proximidad, densidad, isócronas y Suma n_per.

4. Desagregación

El visor habilita campos públicos para desagregar, excluyendo campos sensibles. Campos como ruta, tramo, nivel, rango, grupo, estrato, quintil, decil y segmento pueden usarse para análisis.

Buenas prácticas

  • Usar primero el índice para ubicar la cobertura correcta.
  • Activar solo las capas necesarias para evitar sobrecargar el mapa.
  • Para población usar Suma n_per; no usar promedio de n_per.
  • Revisar siempre la capa activa antes de ejecutar herramientas.
  • Validar resultados con territorio, barrio o manzana según el nivel de análisis.

Resguardo de datos

Las versiones públicas del visor deben excluir campos sensibles como RUT/RUN, teléfonos, correos, nombres de personas naturales, contactos, responsables, propietarios o campos equivalentes. No se debe confundir RUTA con RUT.
