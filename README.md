# Visor Repositorio Digital

Código fuente completo del visor territorial y catálogo cartográfico de la comuna de Santiago.

## Contenido

- Catálogo de coberturas y metadatos.
- Límites de comuna, territorios, barrios y manzanas.
- Capas publicadas de bibliotecas y grifos.
- Red de calles para análisis de isócronas.
- Visualización simple, clúster, mapa de calor y polígono dibujado.
- Proximidad, densidad, tablas, reportes y descargas.
- Publicación automática mediante GitHub Pages.

## Regla de datos

Los archivos originales de la Biblioteca Digital son fuentes de trabajo. Este repositorio contiene únicamente copias preparadas para publicación y no debe utilizarse para modificar los archivos originales.
